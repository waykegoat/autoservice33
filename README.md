# Форсунка 33 — Сайт-визитка дизельного автосервиса (33 регион)

Современный высокопроизводительный сайт-визитка (Single Page Application) для специализированного технического центра по ремонту и стендовой диагностике форсунок **Common Rail**, пьезофорсунок и насос-форсунок в **г. Владимир и Владимирской области (33 регион)**.

Проект разработан с учетом стека и архитектурного стиля [@waykegoat](https://github.com/waykegoat).

---

## 🛠 Стек технологий

- **Фреймворк**: [Vue 3](https://vuejs.org/) (Composition API, `<script setup lang="ts">`)
- **Сборщик**: [Vite 6](https://vite.dev/)
- **Язык**: [TypeScript](https://www.typescriptlang.org/)
- **Иконки**: [@lucide/vue](https://lucide.dev/)
- **Стилизация**: Модульные CSS-переменные, Dark Industrial Automotive палитра (глубокий графит `#0b0d11`, полированная сталь `#161b24`, акцентный янтарно-огненный `#ff6a1a`, стендовый бирюзовый `#00d2ff`), адаптивная верстка (Mobile First).

---

## 🚀 Особенности и разделы

1. **Шапка (`AppHeader`)**:
   - Логотип с символикой форсунки и бейджем региона `[33 RUS]`.
   - Живой статус стенда: пульсирующий индикатор `Приемка открыта • Стенд свободен`.
   - Прямой вызов мастера и мобильное меню-шторка.
2. **Главный экран (`HeroSection`)**:
   - Оффер под 33 регион и быстрый заезд с трассы **М-7 «Волга»** (ул. Куйбышева 26Ж).
   - Интерактивный макет цифрового тест-плана стенда (2500 bar, предвпрыск, налив, обратка, генерация IMA-кода).
3. **Ключевые цифры (`QuickStats`)**:
   - 14 лет опыта, 48 000+ форсунок, стендовый тест-план за 15 минут, точность 0.1 мм³.
4. **Симптомы поломки (`SymptomsSection`)**:
   - Интерактивный чек-лист с оценкой риска (черный дым, долгий запуск, стук под нагрузкой, рост расхода).
5. **Услуги и цены (`ServicesSection`)**:
   - Фильтрация по типам систем (Common Rail Bosch/Delphi/Denso, Piezo, UIS/PDE, бензин GDI, гидродемонтаж, обменный фонд).
6. **Интерактивный калькулятор (`CalculatorSection`)**:
   - Расчет стоимости в реальном времени: выбор типа ТС, бренда аппаратуры, числа форсунок и наличия прикипания. Расчет выгоды по сравнению с покупкой новых деталей.
7. **Лаборатория и стендовый контроль (`EquipmentSection`)**:
   - Описание стендов 2500 bar, ультразвуковой очистки, 20-тонного гидросъемника и таблица сравнения («Форсунка 33» vs «Гаражный мастер» vs «Новые форсунки»).
8. **Бренды и автомобили (`BrandsSection`)**:
   - Bosch, Delphi Technologies, Denso, Continental VDO, Cummins, Scania/Volvo, популярные авто Владимирской области.
9. **Работа по 33 региону (`RegionSection`)**:
   - Фокус на трассы М-7 и М-12 (транзитные дальнобойщики и фуры), прием форсунок из Коврова, Мурома, Александрова, Вязников, Гусь-Хрустального через СДЭК и ТК.
10. **Отзывы (`ReviewsSection`)**:
    - Реальные кейсы владельцев легковых, коммерческих Газелей и автопарков тягачей с рейтингом 4.9/5.
11. **FAQ (`FaqSection`)**:
    - Интерактивный аккордеон с техническими ответами (кодирование IMA, ресурс, демонтаж без снятия ГБЦ).
12. **Контакты и форма (`ContactsSection`)**:
    - Точный адрес во Владимире, кликабельное копирование адреса для Яндекс.Навигатора, прямые ссылки на WhatsApp/Telegram и форма заявки.
13. **Модальное окно бронирования (`ContactModal`)**:
    - Универсальное окно записи с автоподстановкой выбранной услуги, симптома или данных калькулятора.

## 💻 Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000/`.

### 3. Проверка типов и production-сборка
```bash
npm run build
```

### 4. Предпросмотр сборки
```bash
npm run preview
```
